## Как запустить работу

Каждая работа запускается из своей папки, со своим виртуальным окружением:

```bash
cd lab1
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Подробные шаги и результаты описаны в README внутри папки.
